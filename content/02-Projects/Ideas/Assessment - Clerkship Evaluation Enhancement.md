## Germ of the Idea

Help Clerkship Directors write better summative evaluation comments using AI to consolidate observations and generate meaningful feedback for students.

## Overview

### Problem Statement

Clerkship evaluation comments are often generic, lack specificity, or fail to provide actionable feedback due to time constraints and writing challenges.

### Proposed Solution

AI system that analyzes multiple assessment inputs and helps generate specific, actionable, and personalized evaluation comments for summative assessments.

### Success Metrics

- Quality improvement in evaluation comments
- Time savings for Clerkship Directors
- Student satisfaction with feedback received

## Technical Requirements

### AI/ML Components Needed

- Large Language Models for text generation
- Assessment data analysis
- Feedback quality evaluation

### Data Requirements

- Historical evaluation comments
- Assessment rubrics
- Student performance data
- Faculty observation notes

### Integration Points

*Note: These integration requirements are provisional and will be refined based on actual institutional systems and capabilities.*

- Clinical rotation management and scheduling system
- Faculty assessment and evaluation platform
- Student performance tracking and evaluation system
