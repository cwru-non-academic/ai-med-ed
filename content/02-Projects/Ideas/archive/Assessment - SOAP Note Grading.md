## Germ of the Idea

Automated grading system for SOAP notes written by medical students, with existing GitHub implementation as starting point.

## Overview

### Problem Statement

Manual grading of SOAP notes is time-intensive and subjective, creating bottlenecks in clinical skills assessment and feedback delivery.

### Proposed Solution

Implement AI system to automatically grade SOAP notes using NLP techniques, providing consistent and rapid feedback on clinical documentation skills.

### Success Metrics

- Reduction in grading time
- Consistency of grading across evaluators
- Quality of feedback provided to students
